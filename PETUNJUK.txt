BARCODE GENERATOR NOMOR ACAK — PWA OFFLINE

ISI PAKET
- index.html              Aplikasi Barcode Generator (Code 128)
- manifest.webmanifest    Identitas aplikasi PWA
- sw.js                   Service worker untuk cache/offline
- icons/                  Ikon aplikasi

FITUR
- GENERATE BARCODE ACAK: memilih nomor dengan putaran acak.
- PANGGIL NOMOR PILIHAN: memilih nomor tertentu dari daftar.
- Semua nomor diacak per putaran; pada mode random satu putaran selesai sebelum nomor berulang.
- Panggilan manual dihitung ke batas harian dan menghapus nomor itu dari antrean random yang masih menunggu.
- Maksimal 5 kali per nomor per hari, baik panggilan random maupun manual.
- Barcode Code 128 tertanam untuk semua nomor sehingga dapat dibuat offline.
- Hitungan pemakaian tersimpan pada browser/perangkat yang sama.

CARA UPDATE DI GITHUB PAGES
1. Ekstrak ZIP.
2. Ganti index.html dan sw.js di root repository dengan versi terbaru.
3. manifest.webmanifest tetap digunakan; ganti juga bila tersedia di paket.
4. Folder icons tetap di root. Jika sudah benar, tidak perlu diubah.
5. Tunggu GitHub Pages selesai deploy, lalu buka ulang situs.

CATATAN
- PWA memerlukan HTTPS.
- Muat aplikasi sekali saat online agar cache terbaru tersimpan.
- Jika aplikasi terpasang masih menampilkan versi lama, tutup aplikasi lalu buka kembali setelah refresh situs.
